## Visão geral
Este site documenta tecnicamente o mod **Dreams Dimensions** (`dreamsdimensions`) com foco em gameplay, registries, datapack, worldgen, TerraBlender e troubleshooting.

> Escopo desta documentação: conteúdo presente no repositório em `src/main/java` e `src/main/resources`.

## Compatibilidade
- Minecraft: **1.21.11**
- NeoForge: **21.11.x**
- Java: **21**

## Quickstart
1. Execute `./gradlew runClient`.
2. Entre no Overworld, durma até completar o ciclo de sono.
3. Você será enviado para uma dimensão de sonho.
4. Use o item `dreamsdimensions:ow_oneiric_awakener` para retorno.
